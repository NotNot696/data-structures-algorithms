##  مباحث پوشش داده شده:

-  آرایه داینامیک
-  لیست پیوندی
- استک و صف (عادی، حلقوی، با دو استک، اولویت)
-  جدول هش (با چینینگ)
-  درخت (BST، AVL، Trie)
-  هیپ (MaxHeap, MinHeap)
-  گراف (BFS، DFS، تشخیص دور، دیکسترا، پریم)
-  مرتب‌سازی (حبابی، انتخابی، درجی، ادغامی، سریع)
-  جستجو (خطی، دودویی، سه‌گانه)

##  نحوه اجرا:

برای اجرای هر فایل:

```bash
python arrays/dynamic_array.py
python sorting/bubble_sort.py
python searching/binary_search.py
```

برای اجرای تست‌ها:

```bash
python tests/test_sorting.py
python tests/test_searching.py
```
